**使用方法**

1. 在 Revit 里随便开一个文件（空白项目也可以），然后打开 Dynamo。Dynamo 只能在 Revit 里面运行。

2\. 打开图，找到新增的 ④ Batch - RVT files 分组：

* 把 Batch Mode 开关设为 True。
* 在 RVT Files / Folders Code Block 的 files 列表里填 rvt 文件路径或文件夹路径，可以混填。填文件夹时会检查里面所有 .rvt。
* 路径请用正斜杠，例如 "D:/Project/Models"。

3\. Output Folder 选一个文件夹，所有报告都会放在那里。不选的话，每个报告会放在对应 rvt 旁边。

4\. 运行。报告名是 模型名\_ModelCheck\_日期时间.xlsx，完成后会自动打开输出文件夹。



Batch Mode 设为 False 时，和以前一样只检查当前打开的模型。



**运行结果（Watch 节点）**

第 1 项：每个文件对应的 xlsx 路径。

第 2 项：批量汇总表，列出每个文件的结果（OK / ERROR）、检查通过数、整体完成度、报告路径和耗时。

第 3 项：提示信息，比如找不到的路径。



某个文件打开失败时只会在汇总表里记为 ERROR，其他文件照常继续检查。



**批量设置（在 Global Options 里改）**

选项	                默认	作用

DetachFromCentral	true	协同（workshared）文件以分离方式打开，不会锁定或改动中心文件

OpenAllWorksets	        true	设为 false 会快一些，但关闭的工作集里的元素不会被检查

AuditOnOpen	        false	打开文件时是否执行 Audit

IncludeSubfolders	false	填文件夹时，是否连子文件夹一起搜索

SkipBackupFiles	        true	跳过 xxx.0001.rvt 这类备份文件

**注意事项**

**Revit 版本**：比当前 Revit 旧的文件会在内存里自动升级后再检查。因为不保存，原文件不受影响，但打开会比较慢。

**云端模型**：目前只支持本地或网络盘上的路径。BIM 360 / ACC 上的模型要先下载到本地。

**Largest Families**：这项检查会逐个导出族来计算大小，文件一多就很慢。批量运行时建议把它的开关关掉。

**未经 Revit 实测**：我在 Revit 外面测过文件收集（文件夹、子文件夹、跳过备份文件）、规则解析和报告生成，都能跑通。但后台打开 rvt 这部分要在 Revit 里才能验证，请先用两三个文件试一下。
